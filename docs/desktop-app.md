# 桌面版:一个装在电脑里的文献工作台

AI4Paper 桌面版是**独立安装的应用**:不用先装 Zotero,就能管理文献、读 PDF、做笔记、写稿。文献默认保存在**你自己的电脑**上,数据归你自己保管。

提供 macOS(Apple 芯片)和 Windows 10 / 11(64 位)正式版,从[桌面版下载页](https://ai4paper.pro/desktop)获取安装包。

## 适合谁

- 想把文献、PDF 和笔记放在自己电脑上的人。
- 第一次用文献管理软件,想一个应用从找文献走到写作的科研新人。
- 已有 Zotero 资料,想要一个能独立阅读、整理、问答的工作台的人(支持从 Zotero 导入,原资料不受影响)。

## 打开后是什么样

首先看到的是「我的文献」。顶部导航:

**我的文献 · 找文献 · 浏览器 · 笔记 · 素材区 · 写作区 · 更多**

「更多」里有研究综述、研究助理、知识库、管理文献、文献白板和设置。

## 第一次使用,五步走完

1. **装好并登录**:下载安装,右上角点「登录」。
2. **放进第一批文献**:把几篇 PDF 拖进窗口,或从 Zotero 导入已有资料。
3. **分好类**:左侧建文件夹、打标签。
4. **读一篇**:打开阅读器,试一次翻译或问答。
5. **留下笔记**:读到关键处记一条,写稿时带进「写作区」。

## 你能做什么

| 功能 | 一句话 |
|---|---|
| 导入文献 | 导入 PDF、题录文件、DOI,或从 Zotero 搬来资料 |
| 文件夹与标签 | 分层归类,给文献打标签 |
| 检索与筛选 | 按标题、作者、DOI 搜索,按年份、分区、有无全文筛选 |
| 阅读与 AI | 标注、笔记、划词翻译、本文对话、AI 解读 |
| 整理与备份 | 查重、补全题录、每日自动备份与恢复 |
| 云空间 | 需要多台设备接着用时,把文献存入云空间 |

部分 AI 功能需要登录或会员。
