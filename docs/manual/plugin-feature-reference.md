本表逐项对应正式 AI4Paper **10.0.31** 随包功能地图的 **242 条用户项目**，保留同名项目在不同位置的入口，并补充实装阅读器与官网索引中的功能。它是一份可搜索的操作参考；未逐项运行 AI、第三方连接、文件移动或清理。功能地图中包含配套 Web/桌面/浏览器入口，表中按名称区分，不能理解成全是 Zotero 原生功能。

先看[安装与账号](zotero-plugin.md#1-安装登录与第一篇论文)。可选功能默认可能未启用；通用设置→插件功能设置，按需应用后重启。右键工具箱本次未登录时提示先登录产品；不要误以为每个本地类功能都无账号要求。会员、余额和费用均以当前界面为准。

## 如何按本表操作

- **设置项**：进入表中分类→展开对应卡片→修改指定选项→保存/应用→按提示重启→回到目标界面核对。先保留原值或配置备份，不同时改很多项。
- **工具箱项**：选中常规题录或目标分类→右键 AI4Paper 工具箱…→顶部搜索表中功能名→核选中篇数与目标→执行/预览→查回结果。附件型操作另需可用文件。
- **分析/生成项**：选中有对应材料的论文→打开入口→核主题/取材深度/服务/费用→确认→等任务完成→保存或导出→回查原文。只打开窗口不算生成成功。
- **导出/复制项**：核范围→选择字段/样式/目标→预览→复制或保存→在目标软件实际打开；本地链接需要原文库环境。
- **同步/导入项**：备份→确认源、目标、方向、权限→预览范围→先用一条公开资料执行→在目标查回，再考虑批量。看到进度条不等于已同步完整。

“设置”均指 Zotero 设置→AI4Paper；“应用页”从文库顶栏「阅读宇宙应用」打开；“阅”指右侧阅读工作区。找不到入口时先核正确的文库/PDF/分类上下文、账号、定制显隐及模块开关。
