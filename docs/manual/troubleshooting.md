# 遇到问题先检查什么

[手册首页](../tutorials/README.md) · [Web](web-workspace.md) · [Zotero](zotero-plugin.md)

先记录发生时间、所在端、精确版本、操作到哪一步、实际提示及能否用一篇公开样例重现。截图只保留必要界面，遮掉账号、二维码、密钥、设备标识、私人文献和其它窗口。

| 现象 | 按顺序检查 | 看到什么才算解决 |
| --- | --- | --- |
| 下载只有 ZIP | 去正式 Releases 的 Assets 找 `.xpi`；Source code 是源码归档 | 在 Zotero 插件管理器实际安装并核 Enabled/版本 |
| XPI 双击没反应 | Zotero→工具→插件→齿轮→Install Plugin From File | 列表有已启用 AI4Paper |
| 不兼容或看不到插件 | 核 Zotero/XPI 精确版本、插件开关、安装来源；按提示重启 | 版本详情与正式包对应 |
| 找不到旧菜单 | 新版条目右键工具箱搜索；阅→定制；设置→插件功能设置/右键菜单 | 在正确上下文出现入口，不需全开模块 |
| Mac 没有“工具” | 先让 Zotero 活动，再看屏幕顶部菜单栏 | 打开实际 Plugins Manager |
| PDF 白屏/页数为空 | 先在系统阅读器打开原文件，查下载完整性、大小及网络错误；重新取得合法完整文件 | 本机和 Zotero/Web 都渲染正常页数 |
| 有 PDF，写作范围 0 篇 | 查是否只有独立附件，先检索/创建上级题录并核对 | 选中常规题录后处理范围正确 |
| 划词无译文 | 文字可复制吗？浮窗/模块开了吗？服务是否可用且有当前权益？ | 原文、译文和服务状态明确 |
| AI 只看标题/读错论文 | 正文是否解析完成，题录与附件是否同一篇，取材深度是否为标题级 | 回答可对到当前正文与页码 |
| 要求登录/权益 | 登录 AI4Paper 产品→刷新账户状态→核会员/余额；不把 Google/Zotero 登录算产品登录 | 账户状态更新且原动作不再报同错 |
| 知识库没来源 | 核资料范围、索引完成数、嵌入服务及 PDF/快照可读性 | 来源能定位条目或原文；不是只出现答案 |
| 翻译一直排队 | 核是否只入队未启动、原任务状态、实时错误及服务限制 | 原任务运行/完成，译文附件可打开 |
| 翻译失败或中断 | 保留原任务，核错误与余额、网络、文字层；按支持入口续传/重试 | 原任务完成且没有意外重复附件/消耗 |
| Web 换设备文库不见 | 核原浏览器本地存储/文件夹/云空间、账号和授权目录 | 在正确位置看到已知样例及附件 |
| Zotero 换机缺附件/笔记 | 分开核 Zotero 题录、附件和 AI4Paper 数据/设置同步状态 | 目标设备可打开同一论文/笔记，不只看到题名 |
| 同步冲突重复出现 | 保留两侧副本，记录同一条目是否同 key、完成提交后的时间与日志；停止盲目重置 | 有明确的同步成功与两侧一致证据 |
| 导出链接打不开 | 本地 `zotero://`/文件路径需要原库和本地环境；公开分享应另给可访问来源 | 目标使用环境能打开对应资料 |
| 第三方笔记同步重复 | 核目标空间、方向、已同步映射与原任务，先一条公开笔记测试 | 同一条笔记更新到正确位置，无重复 |
| MCP 连不上 | Zotero 正在运行、MCP 已启用、客户端配置完整、认证和当前权益有效 | 只读查询返回公开演示库数据 |
| 快捷键无效 | 核系统/其它插件冲突及自定义键位，查看当前快捷键设置 | 在正确视图触发目标动作 |

不要把清缓存、删配置、重置同步、覆盖数据库或清空回收站当通用修复步骤。涉及整理/恢复先备份；可见“已选择”不代表已点最终完成/保存，“已入队”不代表任务已运行，“已合并代码”也不代表用户已更新插件。

给支持人员的最小材料：系统、Zotero 与插件精确版本（或 Web 时间/页面）、公开样例来源、最短步骤、预期/实际、脱敏错误和时间。不要公开上传整个文库、客户论文、登录信息、同步凭据或完整诊断包。
